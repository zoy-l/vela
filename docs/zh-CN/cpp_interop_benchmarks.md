# Vela 与 C++ 基准：AOT、优化 JIT、反射与双向调用

2026-11-27 在 Windows 11 x64、AMD Ryzen 9 7900X 上完成 Release 采样，**686 个用例、4,802 个样本**全部通过基准校验。
新增的 `struct` 字段负载在 AOT 和可重载优化 JIT 上分别为 **2.390×**、**3.634×**，
方法负载分别为 **4.593×**、**9.065×**。

C++ 为 1×。倍率是 Vela 与本组对应 C++ 的墙钟耗时中位数之比，低于 1× 表示 Vela 耗时更短。
明细中的 Vela 单元格格式为「中位耗时（倍率）」。CV 是 7 次样本墙钟耗时的样本标准差除以均值，顺序与耗时列一致。
[滚动聚合摘要](../../benchmarks/results/rolling_summary.json)的 `latest` 记录每个注册用例的完整中位数、CV、最小值、最大值、计数器和复现命令。

### Struct 与类对照

每次调用创建 1,000 个元素，预留数组容量，执行 16 帧位置更新，最后累加位置并校验整数结果 `1522500`。

## 计时与复现
