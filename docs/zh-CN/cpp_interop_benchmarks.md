# Vela 与 C++ 基准：AOT、优化 JIT、反射与双向调用

2026-11-25 Windows 11 x64 Release，AMD Ryzen 9 7900X。**674 个用例，每项 7 次，共 4718 个样本**，全部通过基准结果与资源校验。
倍率为 Vela 中位 wall time ÷ 同组 C++ 中位 wall time，C++ = 1，越低越好。各组内的规模等权计算几何平均。

[滚动聚合摘要](../../benchmarks/results/rolling_summary.json)的 `latest` 包含全部耗时、波动、计数和复现命令。`previous` 保留 36 项闭合 JIT 的标准 API 专项，完整套件范围不同。

## 计时与复现

LLVM/Clang 23.1.5，C++ 与 Vela 代码生成均为 Release O3，未启用 ThinLTO。各组串行运行，每项最低采样时间 0.2 秒，共 7 次随机交错样本，计入全部样本。

稳态计时排除编译、实例化、输入准备及预热，包含运行时检查、自动 GC 和结果消费。倍率使用各自完整耗时，入口和 control 成本均计入。无匹配 C++ 的反射查询、packed 调用及宿主 API 保留独立耗时。
