# 数学与 UTF-8 字符串 API：C++ 对照基准

2026-11-25 Windows x64 Release O3 实测涵盖 9 项 API，每项两种规模。AOT 和闭合 Baseline JIT（LLVM O3）各使用同组 C++ 样本，合计 72 个用例、504 个样本。所有样本的校验和与 Vela 堆回收检查均通过。

AOT 的几何平均倍率为 **0.920×**，闭合 JIT 为 **0.937×**。
[滚动聚合摘要](../../benchmarks/results/rolling_summary.json)记录全部计数和波动。[综合报告](cpp_interop_benchmarks.md)记录其余 C++ 对照项。

## 对照契约

输入数组在计时前准备为 `0..N-1`。两种实现消费相同输入并检查相同的完整负载结果。
脚本见 [workloads](../../benchmarks/workloads/)，原生实现见
[standard_api_workloads.cc](../../benchmarks/standard_api_workloads.cc)。

| 负载 | 保持一致的工作 |
| --- | --- |
| 四项数学 API | 变化的操作数、int 到 double 转换、同名 C++ 标准数学函数、乘 1000 后舍入和整数校验和；`remainder` 使用 IEEE 最近偶数商语义 |
| 字节边界 | 相同 UTF-8、相同负数/越界/续字节/末尾偏移查询，累加布尔结果 |
| 字节切片 | 相同合法字节区间、复制 26 字节结果、验证结果首尾并计算字节数与码点数；结果超出常见 C++ 小字符串容量 |
| 字节替换 | 相同区间、交替 3/4 字节插入串、一次分配构造最终结果并计算码点数；C++ 先 reserve，再追加三段 |
| 码点到字节偏移 | 相同非法/末尾查询、位置缓存与最近端点选择；C++ 没有退化为每次从头扫描 |
| trim | 相同 Unicode White_Space 判定，混合原样、首尾空白、全空白输入；改变内容时复制并计算码点数 |

字符串基本单元为 `A中😀e\u0301Z\0`，含 13 字节、7 码点；较长输入重复四次，含 52 字节、28 码点。
C++ 使用普通 `std::string` 构造与析构，Vela 使用托管堆和自动 GC，两种生命周期的成本保留在各自计时内。
这些是带循环、调用边界和结果校验的负载对比；两个固定规模不代表任意大文本或真实 UI 场景。

## 配置与复现

公共 Release O3，LLVM/Clang 23.1.5。AOT 使用闭合程序；JIT 使用闭合 Baseline tier、Eager 物化和 LLVM O3。测量范围为两种规模的稳态执行。

采样每项最少 0.2 秒，7 次随机交错。聚合摘要的 `suite.groups.standard_aot` 和 `suite.groups.standard_closed_jit` 保存复现命令和完整过滤器。
