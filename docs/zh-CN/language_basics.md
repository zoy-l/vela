# 基础语言契约

[English](../en/language_basics.md) | [**简体中文**](language_basics.md)

本文档定义 P0 里程碑中的控制流、可空性、作用域规则及诊断信息契约。数值转换始终保持显式；`int` 与 `double` 之间不允许隐式混用。

## Switch 语句

```typescript
switch (value) {
  case 0:
  case 1:
    print("small");
    break;
  default:
    print("other");
}
```

选择器表达式精确求值一次。其类型必须为非空的 `int`、`bool`、`string` 或枚举类型。Case 标签必须具备完全相同的类型且属于编译期常量。支持的常量包括字面量、显式限定的枚举成员、具有常量初始化器的先前 `const` 绑定，以及受支持的一元/二元常量表达式。函数调用、可变变量绑定、数值溢出及除以零均不能作为 case 常量。重复的 case 值以及多个 default 分支均属于语法错误。

空标签共享其后的语句块。非空分支只要存在落入下一个标签的路径，就产生编译错误；应使用 `break`、`continue`、`return`、`throw` 或保证所有路径退出的控制流。最后一个分支允许正常结束。Default 分支可出现在任意位置，并遵循相同规则；仅在没有 case 匹配时才被进入。空的 switch 语句依然会对其选择器表达式求值。

`break` 用于跳出最内层的循环或 switch 语句。`continue` 用于跳转至最内层循环的下一次迭代，直接穿透外围包含的 switch；在 `for` 循环中会执行递增子句。每个 case 分支拥有独立的词法作用域，因此进入后续分支不会观察到先前分支中未初始化的局部变量。若需跨分支共享状态，应在 switch 外层定义变量绑定。

返回值完整性分析会自后向前组合包含 fallthrough 的各分支，消费 switch 的 break 语句，并保留循环的 continue。在缺少 default 时，未匹配的选择器路径构成隐式的 fallthrough 退出路径。穷尽性 `match` 模式匹配表达式是独立的语法结构；详见 [P1 模式匹配契约](core_language.md#normal-enums-and-exhaustive-match-expressions)。

Lowering 保留带类型比较与跳转，原生优化选择最终机器分派方式，包括适用时的表驱动形式。
标签没有运行时求值或分配开销。原生帧与参数预算见[执行契约](native_execution.md)。

## 可空类型

`T?` 精确包含类型 `T` 的所有值以及 `null`。`T` 类型的表达式可以被赋值给 `T?`，且不改变其底层表示或数值。这属于类型拓宽（type widening）；不允许发生隐式数值转换或底层类型的变更。`null` 不能初始化或作为非可空类型的值返回。`?` 后缀描述的是类型本身，并非修饰变量、字段或参数是否可被省略。局部变量声明依然要求显式初始化。

```typescript
func read(value: int?): int {
  if (value == null) return 0;
  return value + 1;
}
```

支持可空参数、局部变量、返回值、类字段及数组元素。`void?` 以及连续的 `??` 后缀均属于语法错误。裸 `null` 初始化器必须附带显式的可空类型标注。数组类型后缀按源码从左到右绑定：

| 类型 | 语义说明 |
| --- | --- |
| `int?[]` | 元素为可空整数的非可空数组 |
| `int[]?` | 元素为非可空整数的可空数组 |
| `int?[]?` | 元素为可空整数的可空数组 |

数组元素类型保持强类型不变性（invariant）：现有的 `int[]` 不是 `int?[]`。数组字面量可根据预期的元素类型进行推导，包括包含 null 元素的数组。

非空检查会在匹配的控制流路径上对局部变量与参数进行类型细化（promotion）。控制流分析能准确识别 `== null`、`!= null`、操作数颠倒、逻辑非 `!`、短路 `&&`/`||` 以及守卫性 early return。局部 `let`、`const` 声明的初始化器与后续赋值使用同一规则：静态类型可证明非空的值建立非空事实；可空值或 dynamic 值不提供这项证明。赋值会替换先前的事实，调用可能修改被闭包捕获的可变局部变量时会使其事实失效。细化不改变变量的声明类型，因此 `int?` 变量仍可重新赋值为 null，也仍可使用 `??`。分支汇聚点取各路径类型事实的交集。循环和 switch 会保守丢弃其内部可能被写入的局部变量类型事实。循环回跳边与 continue 路径无法复用可能被上一次迭代置为无效的断言事实。

```typescript
func main(): void {
  let value: int? = 3;
  print(value + 1); // 4：初始化器已证明 value 非空。
  value = null;
  // print(value + 1); // 错误：value 可能为 null。
}
```

仍可能为 null 的操作数用于数值算术、关系比较、位运算或布尔条件时，诊断会指向该操作数并提示先检查 null。字符串拼接与插值继续按[字符串语境规则](strings.md)格式化可空基本值。

条件表达式的两个分支分别使用对应条件的类型事实，汇合时只保留共同事实。一侧的赋值不会影响另一侧的检查，例如 `value != null ? value.length : 0` 合法。

对象的字段与带索引的数组元素不会被自动类型细化，因为中间操作可能会修改其内容。需要非空值时，可以先将字段值拷贝到局部变量并检查它，或使用空安全操作符：`?.` 在接收者为 null 时跳过成员访问或方法调用，`?.[index]` 在数组为 null 时连同索引表达式一起跳过求值。

`left ?? right` 对左侧求值一次，仅在结果为 null 时求值右侧。它返回选中的值，不会给左侧变量、字段或数组元素赋值。语言不支持 `??=`；需要写回时必须显式赋值。

```typescript
let value: int? = null;
const result: int = value ?? 42; // result 为 42，value 仍为 null。
```

基本值类型支持 null 比较。可空值的相等性比较要求具备相同的底层类型；null 仅与 null 相等。非空字符串按内容比较，基本类型按现有的强类型相等性比较，类对象按引用身份比较。数组与字符串构建器的相等性比较除与 null 比较外均未定义。

寄存器与类字段内部本就使用带标签的 `Value` 槽位存储，因此可空值无需额外的包装对象。可空基本类型数组使用连续的 `Value` 槽位存储。可空引用类型数组保留指针大小的元素存储，使用空指针表示 null。非可空基本类型数组保留紧凑的原生存储。垃圾收集器（GC）扫描引用类型数组并应用其现有的写屏障。

## 作用域与声明顺序

顶层类型、函数签名、类字段与方法签名在分析函数体之前统一先期收集。它们可以引用声明在后文中的符号，包括相互递归的函数调用。类型与函数名称冲突属于编译错误。同一个类内部的字段名与方法名不得冲突。

局部变量在其初始化器通过检查后正式变为可见。初始化器可以引用外层同名的既有绑定；在没有外层绑定的情况下发生局部自引用报错为未知符号名。局部变量必须先声明后使用。同一作用域内的重复声明属于语法错误。函数参数与外层函数体共享同一个词法作用域，因此函数体内不得重新声明同名参数。

嵌套代码块可以遮蔽（shadow）外层的变量绑定。局部变量优先级高于全局函数、构造函数与枚举名称；局部变量值不能被当作函数直接调用。`this` 关键字保留用作常量方法接收者，不可被显式声明或遮蔽。`const` 仅阻止重新赋值绑定，并不阻止通过对象或数组引用修改其内部成员。

`if` 分支或循环体即使不带花括号也拥有独立的局部作用域。`for` 循环的初始化子句对其条件表达式、循环体和递增子句可见，但在循环结束后不再可见。各个 case 分支具有各自独立的作用域。

## 诊断信息源码定位

词法分析器 token、AST 节点及 IR 指令均携带紧凑的源码 ID 以及从 1 开始计数的行号与列号。列号按 UTF-8 字节计数；制表符计为 1 字节，LF 递增行号。包含 CRLF 的源文件同样按每个 LF 递增一次行号。源文件路径在程序中仅存储一份，避免将路径字符串重复拷贝到每个 AST 节点中。

错误诊断信息持有其自身的源码路径副本，因此即使已解析的程序被销毁，诊断结果依然完好存活。文件检查与编译能够准确定位语法与类型错误发生在具体哪个被导入的源文件中。导入路径解析失败精准指向导入语句的字符串字面量。在内存中编译多个源文件时使用 `<source:1>`、`<source:2>` 等内部标识。未命名的单个内存源文件仅保留行号/列号而不输出路径。CLI 统一输出格式为 `path:line:column: error: message`。

重复声明精准指向重复出现的声明 token；枚举中的重复成员保留各自独立的定位信息。未闭合的块注释指向其开头的定界符。语法分析器的错误恢复机制在函数体未闭合时能保留右花括号，并正常解析其后的顶层声明。
