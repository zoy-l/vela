# Vela 语言路线图

[English](../en/roadmap.md) | [**简体中文**](roadmap.md)


这份清单列出了 Vela 基础编程语言的实现任务，涵盖当前初始编译器、带类型的
中间表示（Typed IR）、寄存器虚拟机和隔离实例内独立 GC 基础之上的生产实现工作。

## 当前基础能力

- [x] C/C++ 风格的代码块和分号
- [x] `int` 和 `bool` 类型的值
- [x] 局部变量声明和赋值
- [x] `func`、后置类型标注和局部类型推导
- [x] 整数算术和相等性比较
- [x] 逻辑非运算
- [x] `if` 和 `while`
- [x] 函数和直接函数调用
- [x] 类、固定字段和 param/显式构造
- [x] 枚举及显式限定的枚举成员（`Enum.member`）
- [x] 静态类型检查
- [x] Typed IR 和定长寄存器字节码
- [x] 每个隔离实例独立的精确增量标记清除 GC

## P0：完成基础语言闭环

- [x] 添加 `<`、`<=`、`>` 和 `>=`
- [x] 添加 `&&` 和 `||`
- [x] 添加 `for`
- [x] 添加 `break` 和 `continue`
- [x] 添加 `switch` 和 `case`
- [x] 添加 `null` 字面量和可空性检查
- [x] 添加 `let`/`const` 声明和常量绑定的赋值检查
- [x] 明确作用域、名称遮蔽和先声明后使用的规则
- [x] 为所有解析器和类型检查器错误补全源码位置及诊断信息

P0 行为详见[基础语言契约](language_basics.md)。

## P1：核心值类型和对象模型

- [x] 实现符合 IEEE 754 binary64 的 `double` 值、运算、数组和输出
- [x] 实现 `string`、字符串比较和拼接
- [x] 实现字符串 GC，包含精确根、字段/数组写屏障和纳入内存统计的连续存储
- [x] 解析字符串转义和 Unicode 转义，并诊断非法输入
- [x] 明确使用 UTF-8 存储，长度、索引和切片以 Unicode 码点为单位（不引入独立的 `char` 类型）
- [x] 添加字符串语境中的基本类型/null 自动格式化和基本类型的显式 `toString()`
- [x] 添加最终字符串仅分配一次的数组 `.join(separator)`、字符串操作和由 GC 管理的 `String`
- [x] 添加 Unicode 码点迭代和字素簇 API
- [x] 实现显式数值转换（禁止隐式数值转换）
- [x] 实现类型参数不变的强类型数组、嵌套数组和紧凑连续存储
- [x] 实现可增长的 `T[]`、几何扩容、预留容量和插入/删除 API
- [x] 实现 `Set<T>`
- [x] 实现 `Map<K, V>`
- [x] 将类方法降级为字节码
- [x] 添加 `this` 和 `object.method()` 调用
- [x] 明确字段默认值和构造初始化规则
- [x] 添加静态字段和静态方法
- [x] 添加公有/私有成员的可见性规则
- [x] 添加递归函数支持和递归相关诊断
- [x] 完善函数类型和闭包

## P1：类型系统和模式匹配

- [x] 参考 `std::expected` 实现 `Expected<T, E>`，通过 `ok()` / `err()` 显式构造成功值/错误值
- [x] 添加枚举 `switch`
- [x] 添加穷尽性匹配检查
- [x] 添加 `match` 表达式
- [x] 添加类型别名
- [x] 添加 `T?` 等可空类型
- [x] 添加泛型，例如 `Set<T>` 和 `Map<K, V>`
- [x] 添加显式 interface / implements 契约
- [x] 添加类型判断和带检查的类型转换
- [ ] 添加受检查的动态值、混合容器和动态分派（[设计](json.md)）
- [x] 诊断不可达语句
- [x] 要求每条有限控制流路径都完整返回

核心语言契约详见[核心语言规范](core_language.md)。

## 推荐实现顺序

1. 完善比较、逻辑运算符、`for`、`break` 和 `continue`。
2. 实现字符串，以及采用强类型连续存储的数组。
3. 完善类方法、`this` 和方法调用。
4. 添加控制台输出和首批标准库 API。
5. 添加导入和多文件编译。
6. 添加常量折叠和基础字节码优化。
7. 添加错误处理、调用栈追踪和原生绑定。
8. 修改虚拟机指令分派或 GC 策略前，重新运行 Release 基准测试。

类继承、方法重写和异步任务已经接通源码、类型检查、Typed IR、字节码、VM 与 CLI。
JIT 仍不属于基础语言里程碑。
