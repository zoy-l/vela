# 原生执行契约

[English](../en/native_execution.md) | [**简体中文**](native_execution.md)

Vela 执行由共享 Typed IR 生成的原生代码。JIT 在进程内编译，AOT 生成链接产物；
两者共用值表示、Isolate、堆、宿主绑定、错误传播和异步调度器。

```text
源码 -> 受查 AST -> Typed IR -> 共享原生代码生成
                           -> JIT 目标代码链接 -> NativeInstance
                           -> AOT 目标文件与链接 -> 原生应用
```

## 编译与层级

IR 优化传播常量、消除不可达块和无副作用的废弃值，并保留可观察失败与副作用。
原生 lowering 根据类型与活跃性选择机器表示和精确 GC 根；LLVM 完成机器级优化与寄存器分配。

`run`、源码测试和独立调试器编译封闭快照；`dev` 与 REPL 使用可重载开发会话。
Baseline 和 optimized JIT 都生成原生代码，并遵循相同的语言语义。
可重载优化层保留基线恢复入口及去优化所需状态。
`NativeOptimization::Release` 独立控制 LLVM 优化，因此 baseline 不等于未优化的机器码。

编译失败就是该次请求失败。共享运行时对象不提供另一套执行后端。

## 实例与调用

`jit::CompileSource/Modules/File` 返回编译映像，不创建 Isolate。映像拥有代码及不可变
布局、源码元数据。`NativeInstance` 为接收方 Isolate 创建常量、全局状态和宿主导入绑定，
并在发布实例前验证目标平台、ABI 与宿主签名。不同实例从独立全局状态开始执行。

`ExecuteNativeFunction` 与 `ExecuteNativeCallable` 返回值或明确执行状态，并携带拥有
字符串的诊断和已经解析的栈帧。结果中的 `Value` 借用堆；托管结果须在下一次分配前保根。
导出入口调用还会验证公开导出和参数契约。实例操作只能在所属 Isolate 线程执行。

原生映像包含原生指针和目标相关代码，是编译器产物，不是任意输入指令格式或沙箱。
详见[原生嵌入](native_embedding.md)和[AOT](aot.md)。

## 栈帧、根与限制

逻辑栈帧保留源码调用位置、错误传播和最多 1,024 层调用深度的限制。
原生调用同时检查当前线程的物理栈边界，并保留 64 KiB 用于报告失败与展开。
宿主线程栈较小时，可能在达到逻辑深度上限之前返回 `StackOverflow`。

编译器使用带类型的栈帧存储，并为托管值维护精确影子根。
原生帧聚合超过 4 KiB 时使用可失败的运行时存储；该阈值不是脚本局部变量数量上限。
带类型参数另有 4 KiB 存储预算，由代码生成阶段检查。这些限制与源码整数和数组语义分别定义。

不存在 256 寄存器或 256 泛型特化上限。IR 值和元数据使用 32 位编号。
较多参数、活跃值与长距离分支通过原生代码生成验证，不再压缩成字节宽度操作数。

异步挂起把必要活跃值保存在堆拥有的激活记录中，并释放物理调用栈；完成后退休激活记录。
普通调用不保留解释器寄存器缓存。GC 仍为非移动增量回收器，其工作预算不保证硬实时延迟。

## 诊断与验证

运行时错误使用实际执行版本的不可变源码元数据，调用方位置指向调用指令。
解析后的诊断字符串可晚于机器码退休继续存活。
停止请求返回 `ExecutionStopped`，不成为脚本可捕获的异常；普通异常遵循 catch/finally 语义。

语言回归覆盖完整 int64 与 IEEE binary64 语义、求值顺序、GC 根、递归、闭包、接口、
宿主调用和异步完成。JIT 测试还覆盖两个层级、重载发布与代码退休。
AOT 验收将源码程序与 JIT 对照，并运行独立宿主。
基准中的帧与根指标描述编译计划，不代表实测物理栈用量或进程总内存。
