# 调试器

[English](../en/debugger.md) | [**简体中文**](debugger.md)

`vela debug FILE` 使用 JIT 编译带逐指令检查信息的原生快照，并在无参 `main` 函数的第一条指令前暂停执行。脚本自身的输出打印到 stdout；调试器交互提示与检查信息输出到 stderr。程序正常结束时返回脚本原本的退出状态码；输入 `quit` 或遇到 EOF 将终止执行并以状态码 `0` 退出。

支持的调试命令：

| 命令 | 行为说明 |
| --- | --- |
| `continue`, `c` | 继续执行，直至命中断点或程序结束 |
| `step`, `s` | 单步进入：前进至下一个源码行，会步入 Vela 函数调用 |
| `next`, `n` | 单步跨过：在当前栈帧内跨过子函数调用 |
| `finish`, `f` | 执行直至当前栈帧返回 |
| `stepi`, `si` | 前进一条已生成的 IR 指令 |
| `break [FILE:]LINE`, `b` | 设置源码行断点；省略 FILE 则使用当前选中的栈帧源文件 |
| `break FUNCTION` | 在指定名称的函数或方法入口处设置断点 |
| `breakpoints` | 列出所有断点 ID 及其解析后的具体位置 |
| `delete ID`, `delete all` | 删除指定断点或全部断点 |
| `stack`, `bt` | 打印调用栈帧、PC 指针及调用处源码位置 |
| `frame DEPTH` | 选中指定深度的栈帧进行检查；0 表示最顶层（当前）栈帧 |
| `registers`, `regs` | 显示当前选中栈帧的IR 值内容 |
| `print rN` | 检查单个IR 值的值（不执行任何代码） |
| `field rN INDEX` | 按对象布局索引读取对象的字段值 |
| `element rN INDEX` | 读取数组元素的值 |
| `help`, `h`; `quit`, `q` | 显示帮助菜单；终止程序执行并退出 |

断点支持输入完整源码路径或唯一的文件基准名；若基准名存在歧义，则要求提供完整路径。路径包含空格时需用引号包裹。如果请求断点的行未生成可执行 IR 指令，断点会自动顺延至该文件中下一个可执行代码行，并打印实际解析位置。循环的回跳边可以再次命中同一行断点。函数断点使用栈帧调用栈中展示的名称。单步操作（step/next/finish）始终控制当前实际正在执行的最顶层栈帧，无论当前交互选中检查的是哪一层调用者。

调试器使用共享优化后的 Typed IR；逐指令检查模式禁用对象分配消除，使可检查对象保留真实字段。被死代码消除优化的语句没有对应的停顿指令位置；寄存器检查显示的是IR 值槽位与临时变量，而非源码局部变量名称。调试器不提供执行任意表达式、修改变量值、在 C++ 原生函数内部暂停或异步中断正在运行的 continue 命令的功能。在指令观察者的视角下，原生 C++ 函数调用是原子性的。

## 原生接口与生命周期

嵌入宿主实现 `runtime::NativeDebugger::AtSafepoint`，通过
`isolate.native_control().SetDebugger(&debugger)` 安装观察者。
需要逐指令值检查时以 `NativeDebugging::Instructions` 编译。
普通开发安全点和源码行调试各有自己的停止粒度；安装观察者不会重新生成已有代码。

`NativeDebugContext` 与 `NativeDebugFrame` 只在回调期间借用有效。
栈帧暴露实际执行版本的源码文本、位置、不可变函数身份与层级。
`ReadRegister` 对不可用值或越界编号返回空 optional。深度 0 是当前栈帧，
调用方位置指向调用指令，包括惰性全局初始化期间的嵌套调用。

暂停的原生栈帧仍持有精确 GC 根。观察者可在同一 Isolate 上分配或回收；
需要跨回调保留的引用必须使用 `RootedValue`。
Isolate、执行与调试器须保持有效，销毁观察者前必须解除安装。
推进异步 main 及后台任务期间继续安装调试器，才能检查恢复后的函数。

`NativeDebugContext::RequestStop()` 请求返回 `ExecutionStopped`。
停止不是脚本异常，不执行待处理的 `finally`，也不回滚已有副作用。
栈帧根随展开释放；已停止的运行通过新实例与 Isolate，或开发会话的 Reload 生命周期替换，
不会恢复已经丢弃的原生栈。

普通执行只使用其配置的安全点，不分配逐指令检查数组。
宿主可通过线程安全的原生安全点端点投递停止请求；交互控制台只在暂停时读取命令，
且不能单步进入 C++ 宿主函数体。

## 验证

语言与命令测试覆盖函数和循环断点、step/next/finish、调用方位置、值/字段/数组检查、
观察期间 GC、异常展开与停止。异步命令测试覆盖挂起后的断点，以及退出不产生调度器死锁。
可重载 JIT 测试覆盖两个层级中的源码版本和去优化。
