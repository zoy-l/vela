# 调试器

[English](../en/debugger.md) | [**简体中文**](debugger.md)

`vela debug FILE` 编译或加载与 `run` 命令完全相同的经过校验的字节码，并在无参 `main` 函数的第一条指令前暂停执行。脚本自身的输出打印到 stdout；调试器交互提示与检查信息输出到 stderr。程序正常结束时返回脚本原本的退出状态码；输入 `quit` 或遇到 EOF 将终止执行并以状态码 `0` 退出。

支持的调试命令：

| 命令 | 行为说明 |
| --- | --- |
| `continue`, `c` | 继续执行，直至命中断点或程序结束 |
| `step`, `s` | 单步进入：前进至下一个源码行，会步入 Vela 函数调用 |
| `next`, `n` | 单步跨过：在当前栈帧内跨过子函数调用 |
| `finish`, `f` | 执行直至当前栈帧返回 |
| `stepi`, `si` | 执行单条字节码指令 |
| `break [FILE:]LINE`, `b` | 设置源码行断点；省略 FILE 则使用当前选中的栈帧源文件 |
| `break FUNCTION` | 在指定名称的函数或方法入口处设置断点 |
| `breakpoints` | 列出所有断点 ID 及其解析后的具体位置 |
| `delete ID`, `delete all` | 删除指定断点或全部断点 |
| `stack`, `bt` | 打印调用栈帧、PC 指针及调用处源码位置 |
| `frame DEPTH` | 选中指定深度的栈帧进行检查；0 表示最顶层（当前）栈帧 |
| `registers`, `regs` | 显示当前选中栈帧的物理寄存器内容 |
| `print rN` | 检查单个物理寄存器的值（不执行任何代码） |
| `field rN INDEX` | 按对象布局索引读取对象的字段值 |
| `element rN INDEX` | 读取数组元素的值 |
| `help`, `h`; `quit`, `q` | 显示帮助菜单；终止程序执行并退出 |

断点支持输入完整源码路径或唯一的文件基准名；若基准名存在歧义，则要求提供完整路径。路径包含空格时需用引号包裹。如果请求断点的行未生成可执行字节码指令，断点会自动顺延至该文件中下一个可执行代码行，并打印实际解析位置。循环的回跳边可以再次命中同一行断点。函数断点使用栈帧调用栈中展示的名称。单步操作（step/next/finish）始终控制当前实际正在执行的最顶层栈帧，无论当前交互选中检查的是哪一层调用者。

调试器执行的是优化后的字节码。被死代码消除优化的语句没有对应的停顿指令位置；寄存器检查显示的是物理寄存器槽位与临时变量，而非源码局部变量名称。调试器不提供执行任意表达式、修改变量值、在 C++ 原生函数内部暂停或异步中断正在运行的 continue 命令的功能。在指令观察者的视角下，原生 C++ 函数调用是原子性的。

## 虚拟机接口与生命周期

嵌入式宿主应用可通过实现 `vm::Debugger::BeforeInstruction` 接口并调用 `VirtualMachine::Debug(function, debugger)` 来驱动调试。`DebugContext` 和 `DebugFrame` 仅在回调执行期间作为只读借用视图有效。深度 0 代表当前栈帧；调用方栈帧指向其各自的 call 指令位置，包括嵌套调用或全局变量惰性初始化正在执行期间。找不到符号或超出范围的栈帧/寄存器请求均返回明确的 optional 空结果。

在虚拟机暂停期间，VM 实际分配的连续栈帧保持作为精确 GC 根注册。观察者回调可以检查变量值，并通过同一个 Isolate 进行内存分配或垃圾回收。如果将复制的引用值持久保留至回调结束之后，必须使用常规的宿主保根（rooting）API。严禁在观察者回调中递归执行同一个 VM。Isolate、已编译程序与调试器对象的生命周期必须覆盖整个调用过程。

`DebugAction::Stop` 将向宿主直接返回 `DebuggerStopped` 状态。它不是语言级异常，不会触发待处理的 `finally` 代码块。正在执行中的惰性全局初始化器将恢复为 `Uninitialized` 状态；此前已产生的副作用不会回滚。栈帧和临时异常根在执行终止时自动解绑分离。在异常抛出时继续执行则使用语言内置的标准强类型 catch/finally 和栈展开机制。

普通运行模式实例化不包含观察者路径的解释器主循环模板，不产生任何每条指令的调试检查开销；调试执行模式使用同一套指令实现的独立模板实例化分支。

## 验证与覆盖

编译器测试覆盖了每条暂停指令触发 GC 回收、字符串/数组检查、调用方位置捕获、异常/finally 展开、惰性初始化中断取消、已加载字节码镜像调试及非法入口保护。进程级测试覆盖了函数与循环断点、step/next/finish 单步跳转、栈帧/寄存器/字段/数组元素检查及非法命令处理。
